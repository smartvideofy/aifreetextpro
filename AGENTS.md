# Project rules

- Keep advertising SDK lifecycle and outbound-click observation in one marketing tracking module, separate from Google Analytics, to avoid duplicate installs and mislabelled conversions.
- Use the shared consent module for persisted choices and change notifications; require explicit category acceptance before optional tracking, and preserve versioned choice evidence on withdrawal.
- Marketing pages describe policy and link to authoritative sources; institutional permission and detector scores must never be represented as guarantees of academic compliance.
- Mark static homepage description and social text/URL fallbacks as Helmet-managed so route metadata replaces them without duplicate tags; preserve the static share-image fallback for routes without their own image.
