## What the data actually says

Site totals: 555 clicks / 28,457 impressions / 1.95% CTR / avg position 52.4 desktop, 16.1 mobile.

   `/blog/how-to-check-if-written-by-ai` = 8,479 impressions, CTR 0.01%. It is
   matching "how to detect ai writing" (76.6), "did ai write this" (72.5),
   "detect ai writing" (82.7), "was this written by ai" (77.9), "ai written"

## Phase 1 - Make the 8,479-impression page win (highest priority)

`/blog/how-to-check-if-written-by-ai` stays indexed and becomes the definitive
answer for "how do I tell if AI wrote this":

- Rewrite title/H1/QuickAnswer around the exact matched phrasings: "how to
  detect AI writing", "did AI write this", "was this written by AI".
- Add a scannable signal checklist (the tells: uniform sentence length, hedging
  phrases, absent specificity) with real before/after text samples.
- Add a dated detector-comparison table (accuracy, false-positive rate, free
  word limit) so it can win the snippet the SERP is currently showing.
- Add an FAQ block answering each of the five matched queries verbatim.
- Link to `/ai-checker` for tool intent so the two pages divide informational
  vs transactional instead of competing on the same title.
- Strengthen `/ai-checker` (924 impr, pos 35.8, 1.19% CTR) on transactional
  "check my text / ai checker free unlimited words" phrasing at the same time.

## Phase 2 - Fix the CTR of pages already on page 1 (fastest wins)

Rewrite title and meta description for the nine URLs in finding 3. Rules: lead
with the outcome plus a number, title under 60 chars, description under 155,
include the free-1,000-words hook where relevant. Expected effect is immediate
because ranking is already there.

Then the same treatment for every URL over 100 impressions and under 2% CTR
(28 URLs in the export), prioritising `/blog/does-grammarly-trigger-ai-detection`,
`/blog/how-ai-detectors-work`, `/blog/ai-detection-patterns-explained`,
`/blog/best-chatgpt-prompts-for-essays` (670 impr, pos 62.5), `/compare-ai-humanizers`
(409 impr, pos 66.2), `/api`.

  `/academic-ai-writing-tool` to lift the highest-impression, worst-ranking markets.

  contexts explicitly in the same pages.
- Move Review and Product schema onto the pages that actually deserve
  enhancement (the comparison and tool pages), so rich results attach to URLs
  that can rank.

## Technical notes

- Metadata changes go through each page's existing `SEOHead` props; no new
  components needed.
- New FAQ blocks reuse `EnhancedFAQ` plus the existing FAQPage schema helper so
  structured data stays valid.
- Tables and QuickAnswer blocks reuse `ComparisonTable` and `QuickAnswer`.
- Redirect rules land in both `public/_redirects` and `public/vercel.json`.
- `scripts/seo/check-internal-links.mjs` and `check-sitemap-sync.mjs` run on
  prebuild and must stay green; sitemap count stays at 186 URLs since no pages
  are added or removed in Phases 1-5.

## Measurement

Re-pull GSC weekly and track four numbers: non-branded clicks, non-branded CTR,
average position of `/blog/how-to-check-if-written-by-ai`, and desktop average
position. Phase 1 alone should pull sitewide desktop position from 52 toward 35
within three weeks. Phases 2-3 should move non-branded CTR from 1.06% past 3%.
